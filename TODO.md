## Decisions

- Build on Win32 and Common Controls v6 for a native desktop app that runs on a clean Windows installation.
- Write the host in Rust. Use the `windows-sys` and `windows` crates from `windows-rs` for Win32 and COM bindings. Keep other dependencies to a minimum.
- Follow `roc-native-macos`. Apps declare UI and hold state in Roc. The `roc-signals` engine sends incremental updates over its wire protocol. The host applies them to live Win32 controls and returns events to Roc, one turn at a time on the UI thread.
- Follow `roc-gui` for Windows link inputs. Prebuild the host, generate import libraries from reviewed definitions, and embed our application manifest as a `.res`. Keep Microsoft SDK files and separately distributed Microsoft runtime components out of release artifacts.
